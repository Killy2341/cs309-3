# CS309-3 Assignment

## Part 1: Validation Form
- `validation.html` & `js/validation.js`
- Features real-time validation for Name, Email, Password, Confirm Password, and Age. Prevents submission if errors exist and shows a success message.

## Part 2: Data Table
- `data.html` & `js/table.js`
- Displays an array of objects as a table. Includes a live search filter and buttons to sort by Name and Age.
